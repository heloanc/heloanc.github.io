# Zhonghui Xie — personal website

Bilingual personal research website at **https://heloanc.github.io**.

Plain HTML, CSS and JavaScript; no build step, external fonts, analytics, or third-party scripts. Hosted with GitHub Pages from the root of `main`.

## Files

- `index.html`: introduction, projects, manuscript, experience and education.
- `rsi/blog/index.html`: bilingual RSI-ICD research blog at https://heloanc.github.io/rsi/blog/.
- `research-blog.css` and `research-blog.js`: blog layout, language, reading progress and contents navigation.
- `rsi-icd.html`: legacy RSI-ICD overview.
- `assets/rsi-results.svg`: summary results chart.
- `cv.html`: public CV with print / save-as-PDF support.
- `styles.css`: layout, mobile and print styles.
- `site.js`: language preference and print action.
- `assets/rsi-framework.svg`: original project overview diagram.

Both languages are in the HTML. Keep the English and Chinese versions consistent when editing. Research statements reflect the manuscript at publication of this website; no clinical records or private implementation files are included.
