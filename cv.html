Selected project代表项目

RSI-ICD

Designed and implemented a multi-agent evolution framework that jointly revises executable code and role prompts under fixed model weights. Teacher and verifier agents use paired execution feedback to update the program and revision experience.设计并实现固定模型权重下的多智能体自进化框架，联合修订可执行代码与角色提示词；教师和验证智能体基于配对执行反馈更新程序与改进经验。

On MIMIC-IV ICD-9 / ICD-10, mean diagnosis/procedure micro-F1 improves by 6.53 / 9.90 percentage points over the initial agent across all 200 test records per system. Execution tokens fall by 55.2% / 48.1% on common-success cases, excluding optimization cost.在 MIMIC-IV ICD-9／ICD-10 各 200 例全量测试上，诊断／操作 Micro-F1 均值较初始 Agent 提升 6.53／9.90 个百分点；共同成功病例执行 token 降低 55.2%／48.1%，不含优化成本。
